# Lead skill parity

- `/dt:model` copies the current `dt@dts2` plugin and the orchestrator's skill list into the new lead's backend. Codex no longer keeps an older `dts2-harness` command set once it becomes the lead.
- `/dt:setup` and `/dt:onboard`, after the agent list is final, name agents that lack that plugin or those skills and update their backends without asking.
