- Prompt intake: a `UserPromptSubmit` hook (`hooks/prompt-intake.sh`, 10 s timeout) appends every prompt typed while the harness works to the intake queue, classifies it as fold, clarify or steer, and injects a one-line instruction for the agent. It never blocks a prompt. Off with `intake: false` in `.claude/dts2-harness.local.md`.
- `scripts/intake.py` (`add`, `list`, `resolve`, `answer`, `status`, `hook`) keeps `.harness/intake.jsonl` and renders `.harness/intake.md`. A clarity score (0-100; below 60 the agent may ask at most two short questions at the next safe point, then the item is set on the best reading) decides when an item is set. Flags: `--root`, `--threshold` (default 60), `--budget` (default 2).
- `/dts2:steer <new direction>` is the only command that stops running work: it finishes the current atomic step, stops new dispatch, checkpoints a handoff, reviews open intake items, re-plans to the new direction, confirms in one short message and resumes.
