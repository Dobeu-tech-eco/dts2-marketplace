> Directory edition: do not run bundled scripts or hooks, a package launcher, or a download piped into a shell. Do not read tokens or credential files from the machine. Carry out the step with Read, Edit, Grep, Glob, and git or gh, and write the files the step names.

# Knowledge

For a Cloudflare knowledge store, configure its HTTPS MCP endpoint and bearer token in the plugin configuration. Enter the token in the masked Knowledge token field. Use the connected knowledge tools to list, find, record or remove preferences, terms and learnings when the user requests it. Confirm removals with the user. Keep credentials out of knowledge entries and conversation.

For a local or synced folder, use a folder the user identifies. Store one Markdown entry per key under entries/preference, entries/term or entries/learning. Read the store only when the user invokes this skill.
