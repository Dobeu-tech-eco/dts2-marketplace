# /dt-incidents

Cursor command for the Claude Code command `/dt:incidents`.

This package registers the command so Cursor can show it. It does not run the harness.

Claude Code describes it as: See and learn from agent incidents (hung spawns, missing or partial reports, rework of another agent's files). Subcommands list, live, brief, review, resolve, promote, lessons. Use for incidents, what went wrong with an agent, or review the shift.

Do not run a program from a plugin root or a scripts directory. Do not install a package. Do not read a token or a credential file. Do not merge, push to a default branch, force-push, deploy, or delete a branch.

Detailed instructions, when this workspace is the marketplace repo, are in `plugins/dts2-harness/skills/incidents/SKILL.md`. Those files still name programs this package does not contain. Skip those lines. When a step cannot be done without one, stop and say so.
