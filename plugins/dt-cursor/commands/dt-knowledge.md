# /dt-knowledge

Cursor command for the Claude Code command `/dt:knowledge`.

This package registers the command so Cursor can show it. It does not run the harness.

Claude Code describes it as: Keep your own standing preferences, glossary terms (brands, product lines, repo groups) and cross-project learnings in a private store that follows you across devices. Use for remember this preference, what is my standard setup, look up a term, or sync my knowledge.

Do not run a program from a plugin root or a scripts directory. Do not install a package. Do not read a token or a credential file. Do not merge, push to a default branch, force-push, deploy, or delete a branch.

Detailed instructions, when this workspace is the marketplace repo, are in `plugins/dts2-harness/skills/knowledge/SKILL.md`. Those files still name programs this package does not contain. Skip those lines. When a step cannot be done without one, stop and say so.
