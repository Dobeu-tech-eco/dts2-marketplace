# /dt-composio

Cursor command for the Claude Code command `/dt:composio`.

This package registers the command so Cursor can show it. It does not run the harness.

Claude Code describes it as: Connect Composio so agents reach 1000+ apps through one connection, cache the toolkit map, and offer to disable plugins, MCP servers and skills Composio already covers. Use to set up Composio or trim overlapping tools.

Do not run a program from a plugin root or a scripts directory. Do not install a package. Do not read a token or a credential file. Do not merge, push to a default branch, force-push, deploy, or delete a branch.

Detailed instructions, when this workspace is the marketplace repo, are in `plugins/dts2-harness/skills/composio/SKILL.md`. Those files still name programs this package does not contain. Skip those lines. When a step cannot be done without one, stop and say so.
